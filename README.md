<img width="432" height="31" alt="image" src="https://github.com/user-attachments/assets/fead3017-1804-49d1-992e-f419ad9a2446" /># -澳大利亚儿童教育服务质量分析
该项目的是以来自澳大利亚统计局官网获得的涵盖 1994 年至 2023 年的澳大利亚早期发展普查（AEDC）数据集、学前教育数据集和教育服务数据集为基础做的数据可视化分析。
该项目的目标是从家长的角度出发为儿童选择最好的地区和学校因此为了让数据更具备说服力，我们额外选择了包含教育相关服务提供商的谷歌评论评分和评论。这将使情感分析和质量分析融入到对幼儿服务获取和成效的研究中。
因此我们通过评论和官方数据做可视化数据来分析并制定旨在改善幼儿教育、解决不同地区在教育机会和成果方面差距的政策。

文件1是对澳大利亚的教育服务质量进行宏观的分析，使用matplotlib制作各种不同类型的可视化图片对比每个州的服务数量以及不同领域的服务质量之间的区别，同时分析运营特征，如容量、运营时间和批准日期。探讨这些因素与服务类型、地点或质量评级之间的关联。

文件2是对澳大利亚儿童的发展脆弱性进行深入分析，并探索其与社会经济、地域偏远程度以及学前教育入学情况之间的关系的制作代码。主要目的是找出发展脆弱性比例最高的地区，并分析这些地区多年来的趋势。探究社会经济劣势（通过SEIFA指数衡量）如何与儿童发展脆弱性相关联，包括在国家层面和特定LGA层面的分析。

文件3的代码整合了来自教育服务提供商、Google 评论、社会经济指标 (SEIFA) 和地理空间信息等多个来源的数据，对澳大利亚地方政府区域 (LGA) 的儿童早期发展结果 (AEDC) 进行了全面分析。根据相关的数据集制作了热力图，散点图和空间地图。

文件4分析了澳大利亚的教育服务提供情况，并将其与社会经济指标以及儿童发展脆弱性关联起来

文件5代码整合了澳大利亚教育服务数据和谷歌评论数据，通过探索评论内容、服务特征与区域发展脆弱性之间的关系制作了动态tsne图，通过对数据点进行颜色编码直观地看到高脆弱性区域的评论（蓝色点）和非高脆弱性区域的评论（橙色点）在语义空间中的分布关系，有助于回答高脆弱性区域的谷歌评论是否存在明显的模式这个问题。
